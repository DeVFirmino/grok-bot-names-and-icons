# Checklist

Run through this after the makeover.

## Names

- [ ] Every bot's name says what it does in one or two words.
- [ ] No two bots have names that could be confused.
- [ ] You can find the bot you want without reading the message previews.

## Icons

- [ ] Every bot that should have a custom icon has one. No default shapes left by accident.
- [ ] All icons share one style: same tile shape, stroke weight and padding.
- [ ] Each icon still reads at sidebar size, circle-cropped.
- [ ] No icon contains text, a logo, or a personal photo you didn't mean to use.

## Status

- [ ] Each bot is recorded as applied, waiting or failed.
- [ ] Every "waiting" bot was confirmed by you, in its own chat.
- [ ] Every "applied" bot shows the new icon in the sidebar, after reopening the app if needed.
- [ ] Failures have a note: what was tried and the error.

## Nothing else changed

- [ ] Each bot still has its chat history, memories, files and routines.
- [ ] Nothing was changed outside the app's supported actions.
